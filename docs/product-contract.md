# 产品契约（第一版）

## 用户

刚收房的业主。只改软装和收纳体，不拆墙，不改水电。

## 两段产品

1. 装修预览：确认前可以看三维、换材质、换门窗款式、换活动家具、改柜体。
2. 杂物归位：确认后才做。本期只在柜体槽位上保留 `capacity`，不给归位建议。

## 输入

- 本期示例是已经按米制写好的场景，不经过识图。
- 以后上传的图必须是一层一张的户型平面，不能用房间照片或效果图。
- 只有面积不能定比例。未确认比例时，场景保持 `draft`。
- 层高可以缺省，示例使用 2.8 米。
- 墙和比例未确认前，四类装修命令全部拒绝。

## 只允许四类命令

口语以后也要编译成这四类，不能直接改几何：

1. `change_material`：只改房间地面或墙面材质，不改形状。
2. `change_opening_style`：只改门窗款式，不改洞口宽、高、窗台和位置。
3. `replace_furniture`：只替换活动家具。新物品的宽深高必须落在槽位上限内。
4. `resize_cabinet`：只改柜体槽位的当前尺寸，并重算容量。不能超过槽位上限，单边不能小于 0.2 米。

`frozen` 之后四类命令都拒绝。

## 坐标

- 场景平面单位是米。x 向东，y 向北。
- Three.js：平面 x 仍是 x，平面 y 变成 z，高度是 y。
- 多边形逆时针，不重复首尾点。

## 柜体容量

`volumeM3 = round3(width * depth * height * 0.62)`

`shelves = max(1, floor(height / 0.4) - 1)`

`round3` 是 `Math.round(n * 1000) / 1000`。示例衣柜 1.2 × 0.55 × 2.2 的容积是 0.9，层数是 4。

## 模型

第一版家具和门窗用程序化尺寸体，不下载 GLB。`model.kind` 保留 `gltf`，方便以后换 Kenney 模型。材质第一版用目录里的颜色和粗糙度，不接 Poly Haven 贴图。
